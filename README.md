🎓 CGPA Prediction

A machine learning project designed to predict students' Cumulative Grade Point Average (CGPA) based on relevant academic performance data. The project aims to explore how data analysis and machine learning can help estimate student academic outcomes.

✨ Features
📊 Student academic data analysis
🤖 Machine learning-based CGPA prediction
📈 Identification of patterns in academic performance
🎯 Prediction of student CGPA using relevant input features
